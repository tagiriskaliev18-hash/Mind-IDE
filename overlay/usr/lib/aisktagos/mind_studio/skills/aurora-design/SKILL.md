# Aurora: как оформлять всё, что делает пользователь

Цель — интерфейс, который выглядит дорого и спокойно: много воздуха, один смелый акцент, ноль шума.

## Правила
1. **Основа.** Светлая тема: фон `#ffffff`, вторичный `#f5f5f7`, текст `#1d1d1f`, приглушённый `#86868b`.
   Тёмная: фон `#0b0b10`, поверхность `#14141c`, текст `#f2f2f6`. Только эти нейтрали.
2. **Один акцент на проект.** Выберите цвет под характер продукта и держите его везде (кнопка, ссылка, фокус).
   Градиент бренда AIsktagOS `#9B5DE5 → #5B8DEE → #00D4E8` — только для одного героя-элемента на экране.
3. **Типографика.** Системный шрифт (SF Pro / Segoe UI Variable / Inter). Заголовок 40–56px, вес 600,
   letter-spacing −0.02em; текст 15–17px, межстрочный 1.5. Не больше трёх размеров на экран.
4. **Форма.** Скругления 12–16px у карточек, 999px у таблеток и полей ввода. Границы 1px `rgba(0,0,0,.08)`.
5. **Глубина.** Слоистые мягкие тени: `0 1px 2px rgba(0,0,0,.04), 0 8px 24px rgba(0,0,0,.08)`. Стекло
   (`backdrop-filter: blur(20px) saturate(180%)`) — только для плавающих панелей.
6. **Движение.** 150–250 мс, `cubic-bezier(.2,.8,.2,1)`; появление — сдвиг 6px + прозрачность. Уважайте
   `prefers-reduced-motion`.
7. **Сетка.** Отступы кратны 4 (8, 12, 16, 24, 32, 48). Контент — колонка до 760–1100px по центру.
8. **Доступность.** Контраст текста не ниже 4.5:1, видимый фокус, зоны нажатия от 40px.

## Что отдать в ответе
- Дизайн-токены (CSS-переменные) в начале, затем разметку и стили, которые на них опираются.
- Светлую и тёмную тему сразу.
- Коротко: какой акцент выбран и почему он подходит этому продукту.
