# MindAI — собственная модель MindTagSystem

Цель: модель, которая ставится на любое устройство экосистемы, работает локально и делает работу программиста
так же, как большие облачные модели: сама пишет полноценные программы, запускает и проверяет их. Философия
та же, что у всей экосистемы: **максимальная простота для кодинга**.

## Почему это реально

Маленькая модель проигрывает большой не во всём, а в конкретных навыках. Наш агент Mind уже снимает с модели
половину работы: среда сама выполняет действия, проверяет страницы дымовым тестом, ловит ошибки и возвращает их
модели. Остаётся научить модель трём вещам: строго следовать формату действий, доводить логику до конца и
чинить свои ошибки по подсказкам среды. Это узкая задача, и её решает дообучение на правильных примерах.

## Конвейер

```
 задачи ──► учитель (Claude) ──► проверка в песочнице ──► датасет ──► Soup (LoRA) ──► слияние ──► GGUF ──► Ollama «mindai»
               ▲                                                                                    │
               └──────────────── экзамен: провалы → новые задачи и пары «плохо/хорошо» ◄────────────┘
```

| Шаг | Что | Команда |
|---|---|---|
| 0 | MindAI v0: Qwen3.5-9B с характером Mind, агент сам выбирает её | `ollama create mindai -f mindai/Modelfile` |
| 1 | Экзамен: 8 задач с автопроверкой (игры, сайты, Python, git, починка, вопросы) | `python mindai/bench/run_bench.py --model mindai` |
| 2 | Дистилляция: учитель решает задачи в формате Mind, в датасет идёт только проверенное | `python mindai/distill.py` |
| 3 | Датасет: решения учителя, удачные решения самой модели и работа в Mind Studio (SFT); провалы против удач (DPO) | `python mindai/make_dataset.py` |
| 4 | Дообучение в Soup на RTX 4060 (LoRA, 4 бита, слои потоком) → модель в Ollama → экзамен, одной командой | `python mindai/train.py` |
| 5 | «Суп» специалистов: отдельные LoRA на сайты, Python, git/DevOps, починку — слияние TIES/DARE или эволюционный поиск весов (CMA-ES) по баллам экзамена | `soup adapters merge …` |
| 6 | Слияние, GGUF q4_k_m и `ollama create` (это делает train.py) | `python mindai/build_model.py --adapter … --name mindai` |
| 7 | Снова экзамен. Растёт балл — новая версия MindAI; не растёт — провалы идут в задачи шага 2 | шаг 1 |

Каждая работа агента в Mind Studio записывается в журнал траекторий (`%APPDATA%\aisktagos\mindai\trajectories.jsonl`,
выключается `MINDAI_TRACE=0`): удачные решения сами становятся учебными примерами, неудачные — работой над ошибками.
Чем больше вы работаете с Mind, тем больше у MindAI учебного материала.

## Что уже проверено на этом компьютере

- **Первый экзамен** ([отчёт](bench/results/2026-10-10-first-exam.md)): MindAI v0 (Qwen3.5-9B) — 7 из 8,
  qwen3.5:4b — 6 из 8. Экзамен заодно нашёл три бага среды агента, они исправлены.
- **Весь конвейер обучения** прогнан на Qwen3.5-0.8B: Soup обучил LoRA на 15 примерах первого датасета на RTX 4060
  (пик 7.6 из 8 ГБ), затем слияние, GGUF q4_k_m и `ollama create` — модель ответила «Я — MindAI…».
  Подводный камень Qwen3.5: при слиянии transformers теряет слой multi-token prediction, без него конвертер
  llama.cpp и Ollama модель не принимают; `build_model.py` возвращает его из базы.
- **Учитель Claude** (`distill.py`) работает через ваш вход в Claude Code (модель Sonnet). Хуки Claude Code для
  него выключены с вашего разрешения: хук проверки правок перехватывал ответы учителя. Первые 3 задачи — 3 решения
  прошли проверку.

## Выбор базы

У Qwen3.5 нет версии на 14B: есть 9B и 27B. **База по умолчанию — Qwen3.5-9B**: новейшее поколение, в 4 битах
целиком помещается в 8 ГБ видеокарты и работает быстро. Вариант 14B (Qwen3-14B, прошлое поколение) подготовлен в
`soup/mindai-sft-14b.yaml`: он учится с подачей слоёв потоком и в работе частично уходит в оперативную память.
